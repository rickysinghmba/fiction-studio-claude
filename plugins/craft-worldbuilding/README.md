# Worldbuilding

_Magic and technology with costs and limits, shown through the story, never dumped._

Keeps an invented world consistent and alive: rules for magic or technology with real costs and limits, places and cultures that affect what characters can do, and world details delivered through action and conflict instead of lectures. Checks new facts against the story bible so the world doesn't contradict itself.

## What it changes

- Your Claude reveals the world through what characters do and want
- The copy editor checks names and world facts against the story bible
- The development editor flags info-dumps and rules that bend for convenience

**Good for:** Fantasy, science fiction, romantasy, dystopian and any invented world.

**Skip it if:** Your book is set in the real present-day world.

## Install

```
/plugin install craft-worldbuilding@convertsprint
```

Then ask Claude to draft or review with worldbuilding, or just write: Claude uses it when it's relevant.
