# Store listing

_Description, keywords and categories for online bookstores, aimed at the right readers._

When your Claude prepares a store listing, it writes the book description (with a bold hook line and short paragraphs that read well on a phone), suggests search keywords readers of your genre actually type, proposes categories, and asks you for comparable titles rather than guessing them.

## What it changes

- Your Claude prepares the description, keywords and categories for a listing
- Asks you for comparable titles instead of inventing them

**Good for:** Getting a book ready to sell in online stores.

**Skip it if:** You only sell through your own author page.

## Install

```
/plugin install craft-store-listing@convertsprint
```

Then ask Claude to draft or review with store listing, or just write: Claude uses it when it's relevant.
