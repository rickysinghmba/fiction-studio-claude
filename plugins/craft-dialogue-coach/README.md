# Dialogue coach

_Each character sounds like themselves and only knows what they should._

Checks every speaking character's lines for voice (would only this person say it this way?), knowledge (do they know something they can't yet?) and subtext (do people say exactly what they mean?). Suggested fixes keep the line's job in the story.

## What it changes

- The development editor reviews dialogue character by character
- Your Claude writes dialogue with more subtext

**Good for:** Dialogue-heavy books, ensembles, romance and banter.

**Skip it if:** Your book has very little dialogue.

## Install

```
/plugin install craft-dialogue-coach@convertsprint
```

Then ask Claude to draft or review with dialogue coach, or just write: Claude uses it when it's relevant.
